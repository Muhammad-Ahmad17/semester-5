═══════════════════════════════════════════════════════════════════════════════
ADVANTAGES vs DISADVANTAGES
═══════════════════════════════════════════════════════════════════════════════

BISECTION
  ✓ Always converges if bracket exists
  ✓ Simple to understand and code
  ✓ Robust
  ✗ Slow convergence
  ✗ Must bracket root first

NEWTON-RAPHSON
  ✓ Very fast (quadratic)
  ✓ No need to bracket
  ✓ Standard method
  ✗ Needs derivative
  ✗ May diverge from bad start
  ✗ Fails at f'(x) = 0

SECANT
  ✓ No derivative needed
  ✓ Reasonably fast
  ✓ Only one function evaluation per iteration
  ✗ Needs two starting points
  ✗ May diverge
  ✗ No guaranteed convergence

REGULA FALSI
  ✓ Always converges if bracket exists
  ✓ Faster than bisection
  ✓ No derivative needed
  ✗ Slower than open methods
  ✗ Must bracket root first

FIXED POINT
  ✓ Simple iteration
  ✓ Many forms available
  ✗ Convergence depends on g(x) choice
  ✗ Need |g'(x)| < 1
  ✗ Rearrangement not always obvious

MODIFIED NEWTON-RAPHSON
  ✓ Excellent for multiple roots
  ✓ Very fast convergence
  ✓ Handles f'=0 case
  ✗ Need first and second derivatives
  ✗ Complex formula
  ✗ Only for multiple roots

═══════════════════════════════════════════════════════════════════════════════
INITIALIZATION PATTERNS
═══════════════════════════════════════════════════════════════════════════════

ALL METHODS:
    clc; clear; close all;
    tol = 1e-6;
    maxIter = 50;
    i = 0;
    err = inf;

BRACKET METHODS (Bisection, Regula Falsi):
    a = input('Enter a: ');
    b = input('Enter b: ');
    while f(a)*f(b) > 0
        % Re-enter values
    end

OPEN METHODS (Newton, Secant, Fixed Point, Mod-NR):
    x0 = input('Enter initial guess: ');

SPECIAL - Secant:
    x0 = input('Enter x0: ');
    x1 = input('Enter x1: ');


═══════════════════════════════════════════════════════════════════════════════
ITERATION UPDATE PATTERNS
═══════════════════════════════════════════════════════════════════════════════

Bisection:
    Xm = (a + b) / 2;
    if f(a) * f(Xm) < 0
        b = Xm;
    else
        a = Xm;
    end
    Xm_old = Xm;

Newton-Raphson:
    x_new = x0 - f(x0) / df(x0);
    x0 = x_new;

Secant:
    x2 = x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0));
    x0 = x1;
    x1 = x2;

Regula Falsi:
    x_new = (a*f(b) - b*f(a)) / (f(b) - f(a));
    if f(a) * f(x_new) < 0
        b = x_new;
    else
        a = x_new;
    end
    x_old = x_new;

Fixed Point:
    x_new = g(x0);
    x0 = x_new;

Modified NR:
    x_new = x0 - (f0*f1) / (f1^2 - f0*f2);
    x0 = x_new;


═══════════════════════════════════════════════════════════════════════════════
ERROR CALCULATION PATTERNS
═══════════════════════════════════════════════════════════════════════════════

All methods use same error formula:
    
    if i == 1
        err = inf;
    else
        err = abs((x_new - x_old) / x_new) * 100;
    end

Where:
    - x_new: current value
    - x_old: previous value
    - Multiplying by 100 gives percentage

Alternative (Absolute error - rarely used):
    err = abs(x_new - x_old);


═══════════════════════════════════════════════════════════════════════════════
WHEN EACH METHOD FAILS
═══════════════════════════════════════════════════════════════════════════════

Bisection:
    ✗ f(a) and f(b) have same sign (not bracketing)
    ✗ Discontinuity between a and b

Newton-Raphson:
    ✗ Starting too far from root
    ✗ f'(x₀) = 0 (tangent vertical)
    ✗ f'(x) is hard to compute
    ✗ Root has high multiplicity

Secant:
    ✗ Very poor starting guesses
    ✗ Function oscillating wildly
    ✗ Roots very far apart

Regula Falsi:
    ✗ Can't bracket the root
    ✗ Discontinuity in bracket

Fixed Point:
    ✗ |g'(x)| ≥ 1 throughout domain
    ✗ No suitable rearrangement found
    ✗ g(x) undefined in search region

Modified NR:
    ✗ f'' is hard to compute
    ✗ f'² - f·f'' = 0 (singularity)
    ✗ Not a multiple root (should use regular NR)
