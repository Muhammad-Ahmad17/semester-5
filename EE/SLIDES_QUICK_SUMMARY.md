## 📚 CHAPTER 1: Introduction to Process Economics

### Key Topics:
- **Production**: How much goods and services individuals, businesses, and countries make
  - **Goods**: Tangible products (can touch)
  - **Services**: Work performed for others

### 4 Factors of Production:
1. **LAND** - Natural Resources (water, oil, gas, trees)
2. **LABOR** - Physical and intellectual manpower
3. **CAPITAL** - Tools, machinery, factories (things to make things)
4. **ENTREPRENEURSHIP** - Investment money and risk-taking

### Production Process Flow:
```
Land + Labor + Capital + Entrepreneurship 
    → Production/Manufacturing 
        → Goods & Services 
            → Consumers
```

### Economic Activities:
- **Consumption**: Using wealth to fulfill basic needs for maximum utility
- **Distribution**: Paying factors of production (rent, wages, interest, profit)
- **Exchange**: Wealth transfer between individuals and countries (trade)

### Definition:
*"Economics is the study of how people and society choose to employ scarce resources that could have alternative uses to produce various commodities and distribute them for consumption, now or in the future."*

### Economic Models:
- **2-Sector Economy**: Households ↔ Firms
- **3-Sector Economy**: Households ↔ Firms ↔ Government

## 💰 CHAPTER 3: Interest Formulas and Applications

### Key Formulas:

#### 1. **Single-Payment Compound Amount**
- Find future value (F) of present amount (P)
- Formula: **F = P(1 + i)^n**
- Example: Rs. 20,000 @ 18% for 10 years

#### 2. **Single-Payment Present Worth**
- Find present value (P) of future sum (F)
- Formula: **P = F/(1 + i)^n = F(P/F, i, n)**
- Example: Need Rs. 1,00,000 in 10 years @ 15%

#### 3. **Equal-Payment Series Compound Amount**
- Future worth of equal annual payments
- Formula: **F = A × [((1+i)^n - 1) / i]**
- Example: Rs. 10,000/year for 25 years @ 20%

#### 4. **Equal-Payment Series Sinking Fund**
- Equal annual deposits to reach future sum
- Find annual payment (A) to reach target (F)
- Example: Save Rs. 5,00,000 in 15 years

### Key Concepts:
- **Compound Interest**: Interest on principal + accumulated interest
- **Time Value of Money**: Money today is worth more than same amount in future
- **Annuity**: Series of equal payments at regular intervals

## 📊 CHAPTER 4: Present Worth Method of Comparison

### Method Overview:
- **Purpose**: Compare investment alternatives by reducing cash flows to present value (time zero)
- **Approach**: Assume interest rate (i) and calculate present worth (PW) of each option
- **Decision**: Select alternative with best (highest/least negative) present worth

### Two Types of Decision Problems:

#### 1. **Revenue-Dominated Cash Flow**
- Focus on revenue generation
- Select option with **highest positive PW**
- Example: Choosing between technologies with different revenue streams

#### 2. **Cost-Dominated Cash Flow**
- Focus on minimizing costs
- Select option with **lowest cost (least negative PW)**
- Example: Choosing between machines with different costs

### Key Formula:
**PW = -Initial Investment + PV of Future Cash Flows**

Where: **PV of Annuity = A × [((1+i)^n - 1) / (i(1+i)^n)]**

### Example Applications:
1. **Technology Selection**: Compare 3 technologies based on initial cost and annual revenue
2. **Elevator Bid Comparison**: Choose between two bids with different costs and lifespans
3. **Investment Proposal Comparison**: Compare net cash flows at 18% interest
4. **Purchase Decision**: Down payment vs. installment payment @ 18%

### Decision Rule:
- For revenue projects: **Maximum PW wins**
- For cost projects: **Minimum (least negative) PW wins**

## 📈 CHAPTER 5: Elasticity and Its Application

### Price Elasticity of Demand (PED)

#### Definition:
Measure of how responsive quantity demanded is to price changes

#### **Midpoint Method Formula:**
```
PED = (ΔQ/Average Q) / (ΔP/Average P)
PED = [(Q₂ - Q₁) / ((Q₁ + Q₂)/2)] / [(P₂ - P₁) / ((P₁ + P₂)/2)]
```

#### Example Calculation:
- Hotel rooms: P = $70 → Q = 5,000; P = $90 → Q = 3,000
- Calculate elasticity using midpoint method

### Determinants of Price Elasticity:

1. **Availability of Close Substitutes**
   - More substitutes → More elastic demand
   
2. **Necessities vs. Luxuries**
   - Necessities (insulin) → **Inelastic** (small PED)
   - Luxuries (Caribbean cruises) → **Elastic** (large PED)
   
3. **Definition of Market**
   - Narrowly defined → More elastic
   - Broadly defined → Less elastic
   
4. **Time Horizon**
   - Short run → Less elastic
   - Long run → More elastic

### Demand Curve Classifications:

1. **Perfectly Inelastic** (PED = 0)
   - Vertical line
   - Quantity doesn't change with price
   
2. **Inelastic** (PED < 1)
   - Steep curve
   - % change in Q < % change in P
   
3. **Unit Elastic** (PED = 1)
   - % change in Q = % change in P
   
4. **Elastic** (PED > 1)
   - Flat curve
   - % change in Q > % change in P
   
5. **Perfectly Elastic** (PED = ∞)
   - Horizontal line
   - Infinite response to price change

### Rule of Thumb:
- **Flatter curve** = **Bigger elasticity** (more responsive)
- **Steeper curve** = **Smaller elasticity** (less responsive)

## 💼 ELEMENT OF COST & BREAK-EVEN ANALYSIS

### Cost Classification:

#### 1. **Variable Cost (VC)**
- Varies with production volume
- Example: Raw materials, direct labor
- Formula: **VC per unit × Quantity**

#### 2. **Fixed Cost (FC)**
- Constant regardless of production volume
- Example: Rent, salaries, depreciation
- Remains same at all production levels

#### 3. **Total Cost (TC)**
- **TC = Fixed Cost + Variable Cost**
- **TC = FC + (VC per unit × Q)**

---

### Break-Even Analysis

#### **Definition:**
Point where **Total Revenue = Total Cost** (Profit = 0)

#### **Break-Even Point (BEP)**
The cut-off production volume where firm starts making profit

#### Key Variables:
- **s** = Selling price per unit
- **v** = Variable cost per unit
- **FC** = Fixed cost per period
- **Q** = Volume of production

#### **Break-Even Equation:**

**Step 1:** Revenue - Costs = Profit

**Step 2:** Revenue - Variable Cost - Fixed Cost = Profit

**Step 3:** At Break-Even, Profit = 0
- Revenue - Variable Cost - Fixed Cost = 0
- **Revenue = Variable Cost + Fixed Cost**

**Step 4:** Revenue = #Units Sold × Selling Price

#### **Break-Even Formula:**
```
At BEP: s × Q = (v × Q) + FC
s × Q - v × Q = FC
Q(s - v) = FC

BEP (Quantity) = FC / (s - v)
BEP (Sales $) = BEP Quantity × Selling Price
```

Where:
- **(s - v)** = **Contribution per unit**

### Break-Even Graph Components:

```
$
│                    / Revenue Line (slope = s)
│                  /
│                /  ← Profit Zone (above BEP)
│              /
│    BEP →  ●────────────
│          /  
│        /  ← Loss Zone (below BEP)
│      /
│    / Total Cost Line (starts at FC, slope = v)
│  /
│/_________________ Fixed Cost Line
└────────────────── Quantity (Q)
```

### Key Points on Graph:
- **Y-intercept of TC line** = Fixed Cost (FC)
- **Slope of Revenue line** = Selling price (s)
- **Slope of TC line** = Variable cost per unit (v)
- **Break-Even Point** = Intersection of Revenue and Total Cost lines
- **Below BEP** = Loss Zone (TC > Revenue)
- **Above BEP** = Profit Zone (Revenue > TC)

## 🎯 KEY FORMULAS SUMMARY

### Time Value of Money:
1. **Future Value**: F = P(1 + i)^n
2. **Present Value**: P = F/(1 + i)^n
3. **Annuity Future Worth**: F = A × [((1+i)^n - 1) / i]
4. **Annuity Present Worth**: P = A × [((1+i)^n - 1) / (i(1+i)^n)]

### Cost Analysis:
1. **Total Cost**: TC = FC + VC = FC + (v × Q)
2. **Total Revenue**: TR = s × Q
3. **Profit**: Profit = TR - TC = (s × Q) - [FC + (v × Q)]

### Break-Even:
1. **BEP (Units)**: Q = FC / (s - v)
2. **BEP (Sales)**: BEP Sales = Q × s
3. **Contribution per unit**: s - v
4. **Contribution Margin Ratio**: (s - v) / s

### Elasticity:
1. **Price Elasticity (Midpoint)**: PED = (ΔQ/Avg Q) / (ΔP/Avg P)
2. **Interpretation**: 
   - |PED| > 1 = Elastic
   - |PED| = 1 = Unit Elastic
   - |PED| < 1 = Inelastic
