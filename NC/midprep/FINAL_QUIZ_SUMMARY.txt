⚡ THE 6 FORMULAS - MEMORIZE THESE!
═══════════════════════════════════════════════════════════════════════════════

1️⃣  BISECTION
    Xm = (a + b) / 2
    if f(a)*f(Xm) < 0, b = Xm; else a = Xm; end

2️⃣  NEWTON-RAPHSON
    x_new = x0 - f(x0) / df(x0)

3️⃣  SECANT
    x2 = x1 - f(x1)*(x1 - x0)/(f(x1) - f(x0))

4️⃣  REGULA FALSI
    x_new = (a*f(b) - b*f(a)) / (f(b) - f(a))
    if f(a)*f(x_new) < 0, b = x_new; else a = x_new; end

5️⃣  FIXED POINT
    x_new = g(x0)

6️⃣  MODIFIED NEWTON-RAPHSON
    x_new = x0 - (f(x0)*df(x0)) / (df(x0)^2 - f(x0)*d2f(x0))

🔍 QUICK IDENTIFICATION GUIDE
═══════════════════════════════════════════════════════════════════════════════

You see in the problem...          You need to use...

"interval [a,b]" + "f(x)=0"       Bisection or Regula Falsi
"initial guess x0" + "f(x)=0"     Newton or Fixed Point or Secant
"find derivative f'(x)"            Newton-Raphson
"two guesses x0, x1"               Secant Method
"g(x) form" or "rearrange"        Fixed Point Iteration
"multiple root" + "f'(x)=0"       Modified Newton-Raphson
"NO derivative available"          Bisection or Secant
"NO bracket available"             Newton or Secant or Fixed Point

💡 MEMORY AIDS - Teach yourself these!
═══════════════════════════════════════════════════════════════════════════════

BISECTION = "cut in middle"
    Think: Cutting sandwich in half each time

NEWTON-RAPHSON = "draw tangent line"
    Think: Slope formula: x_new = x_old - rise/slope

SECANT = "draw secant line between points"
    Think: Like Newton but with finite difference

REGULA FALSI = "weighted average"
    Think: Linear interpolation through two points

FIXED POINT = "fixed point on graph"
    Think: Where y = x intersects with y = g(x)

MODIFIED NEWTON-RAPHSON = "Newton for multiple roots"
    Think: Handles tangent touches (where f' = 0 too)

⚠️ CRITICAL MISTAKES - AVOID AT ALL COSTS!
═══════════════════════════════════════════════════════════════════════════════

❌ NOT initializing i and err before loop
   → Code won't work, will print garbage

❌ Using absolute error instead of relative error
   → Wrong convergence criterion

❌ Not checking bracket condition for closed methods
   → May not find root even if one exists

❌ Forgetting to update variables at loop end
   → Infinite loop or no convergence

❌ Wrong derivative formula
   → Always verify your calculus!

❌ Printf in wrong place (after loop instead of before)
   → No header, confusing output

❌ Different update rules for different methods
   → Study patterns carefully!

❌ Forgetting @(x) in function definition
   → Syntax error
