## 🔴 TOP 10 CRITICAL FORMULAS (Memorize!)

### 1. Breakeven Quantity ⭐⭐⭐
$$\boxed{BEQ = \frac{FC}{s - v}}$$
- **FC** = Fixed Cost
- **s** = Selling price per unit
- **v** = Variable cost per unit
- **Use:** "Find breakeven point" (90% of cost problems)

---

### 2. PED Midpoint Method ⭐⭐⭐
$$\boxed{PED = \frac{|Q_2 - Q_1|}{|P_2 - P_1|} \times \frac{(P_2 + P_1)/2}{(Q_2 + Q_1)/2}}$$
- **Use:** Given two (P, Q) points
- **Always positive**, use midpoint as base

---

### 3. Profit
$$\boxed{\text{Profit} = Q(s - v) - FC}$$
- **Q** = Quantity
- **Use:** Profitability at any output level

---

### 4. Total Revenue
$$\boxed{TR = P \times Q}$$
- **Use:** Revenue calculations, with elasticity

---

### 5. P/V Ratio
$$\boxed{\text{P/V Ratio} = \frac{s - v}{s} \times 100}$$
- **Use:** Contribution per dollar/rupee of sales
- Alternative: Profit = (Sales × P/V) - FC

---

### 6. Income Elasticity (YED)
$$\boxed{YED = \frac{\Delta Q_d / Q_d}{\Delta Y / Y}}$$
- **>1** = Luxury | **0-1** = Necessity | **<0** = Inferior
- **Use:** "Classify good"

---

### 7. Cross-Price Elasticity (XED)
$$\boxed{XED = \frac{\Delta Q_{d,A} / Q_{d,A}}{\Delta P_B / P_B}}$$
- **>0** = Substitutes | **<0** = Complements
- **Use:** "Relationship between goods"

---

### 8. Equilibrium
$$\boxed{Q_d = Q_s}$$
- **Use:** Set equal, solve for P

---

### 9. Marginal Cost
$$\boxed{MC = \frac{\Delta TC}{\Delta Q}}$$
- **Use:** Cost of one more unit

---

### 10. Marginal Revenue
$$\boxed{MR = \frac{\Delta TR}{\Delta Q}}$$
- **Use:** Revenue from one more sale

## 💰 TOTAL REVENUE RULES (CRITICAL!)

| Elasticity | Price ↑ | Price ↓ | Strategy |
|------------|---------|---------|----------|
| **Inelastic (PED < 1)** | TR ↑ | TR ↓ | ✅ RAISE price |
| **Elastic (PED > 1)** | TR ↓ | TR ↑ | ✅ LOWER price |
| **Unit Elastic (PED = 1)** | TR same | TR same | Price doesn't help |

**Use:** "Should we increase price to increase revenue?"

## 📊 ELASTICITY QUICK GUIDE

### PED (Price Elasticity of Demand)

| Value | Type | Demand Curve | Example |
|-------|------|--------------|---------|
| **0** | Perfectly Inelastic | Vertical | Life-saving drugs |
| **<1** | Inelastic | Steep | Necessities (salt) |
| **=1** | Unit Elastic | Medium | - |
| **>1** | Elastic | Flat | Luxuries (cruises) |
| **∞** | Perfectly Elastic | Horizontal | Perfect competition |

---

### YED (Income Elasticity)

| Value | Type | Example |
|-------|------|---------|
| **>1** | Luxury (income elastic) | Sports cars |
| **0 to 1** | Necessity (income inelastic) | Food, fuel |
| **<0** | Inferior good | Low-quality items |

---

### XED (Cross-Price Elasticity)

| Value | Relationship | Example |
|-------|--------------|---------|
| **>0** | Substitutes | Tea & Coffee |
| **<0** | Complements | Car & Gas |
| **=0** | Unrelated | - |

## 🎯 DECISION FLOWCHART

### "Find breakeven"
→ **BEQ = FC/(s-v)**

### "Two (P,Q) points"
→ **PED Midpoint Method**

### "Profit at Q units"
→ **Profit = Q(s-v) - FC**

### "Should raise price?"
→ Calculate **PED** → Check TR rule

### "Substitutes or complements?"
→ **XED** (positive = sub, negative = comp)

### "Luxury or necessity?"
→ **YED** (>1 = luxury, 0-1 = necessity)

## 📝 SAMPLE CALCULATIONS

### Example 1: Breakeven
```
Given: s = $50, v = $30, FC = $500
BEQ = 500/(50-30) = 500/20 = 25 units ✓
```

---

### Example 2: PED Midpoint
```
Given: P₁=$10, Q₁=100 → P₂=$12, Q₂=80

Midpoints: P=11, Q=90

%ΔP = |12-10|/11 = 2/11 = 18.2%
%ΔQ = |80-100|/90 = 20/90 = 22.2%

PED = 22.2/18.2 = 1.22 (Elastic) ✓
```

---

### Example 3: YED
```
Given: Y₁=500, Q₁=20 → Y₂=600, Q₂=25

YED = (5/20) / (100/500)
    = 0.25 / 0.20 = 1.25

YED > 1 → Luxury ✓
```

---

### Example 4: Profit
```
Given: s=$50, v=$30, FC=$500, Q=30

Profit = 30(50-30) - 500
       = 30(20) - 500
       = 600 - 500 = $100 ✓
```

## ⚠️ COMMON TRAPS TO AVOID

### ❌ DON'T:
1. Use **FC/v** for BEQ (WRONG!)  
   ✅ Use **FC/(s-v)**

2. Use starting value as base for %  
   ✅ Use **midpoint** for PED

3. Drop sign from XED  
   ✅ Keep sign (tells substitutes vs complements)

4. Report PED as negative  
   ✅ Always take **absolute value**

5. Forget units in final answer  
   ✅ Always write **units**, $, %, etc.

## 📚 COST FORMULAS

### Total Cost
$$TC = TVC + TFC = (v \times Q) + FC$$

### Contribution
$$\text{Contribution} = s - v$$

### Margin of Safety
$$\text{MOS} = \text{Actual Sales} - \text{BE Sales}$$
$$\text{MOS\%} = \frac{\text{Actual - BE}}{\text{Actual}} \times 100$$

### Profit using P/V
$$\text{Profit} = (\text{Sales} \times \text{P/V Ratio}) - FC$$

### Required Sales for Target Profit
$$\text{Required Sales} = \frac{FC + \text{Desired Profit}}{\text{P/V Ratio}}$$

## ⚖️ MARKET EQUILIBRIUM

### Equilibrium
$$Q_d = Q_s$$

### Shortage (Excess Demand)
$$Q_d > Q_s \Rightarrow \text{Price} \uparrow$$

### Surplus (Excess Supply)
$$Q_s > Q_d \Rightarrow \text{Price} \downarrow$$
