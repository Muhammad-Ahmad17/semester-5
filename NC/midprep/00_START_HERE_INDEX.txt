🎓 THE 6 METHODS IN THIS PACKAGE
═══════════════════════════════════════════════════════════════════════════════

1. BISECTION METHOD
   → Find root in bracket [a,b]
   → Slow but reliable
   → Formula: Xm = (a + b) / 2

2. NEWTON-RAPHSON METHOD
   → Find root near guess x0
   → Fast (quadratic convergence)
   → Formula: x = x0 - f(x0)/f'(x0)

3. SECANT METHOD
   → Find root without derivative
   → Two guesses needed
   → Formula: x2 = x1 - f(x1)·(x1-x0)/(f(x1)-f(x0))

4. REGULA FALSI (False Position)
   → Find root in bracket using linear interpolation
   → Better than bisection
   → Formula: x = (a·f(b) - b·f(a))/(f(b) - f(a))

5. FIXED POINT ITERATION
   → Solve x = g(x)
   → Need to rearrange equation first
   → Formula: x = g(x)

6. MODIFIED NEWTON-RAPHSON
   → For multiple roots
   → Need f'(x) and f''(x)
   → Formula: x = x0 - (f·f')/([f']² - f·f'')
