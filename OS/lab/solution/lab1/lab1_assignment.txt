16.Top Command:
$top
Task 16: Execute top command and interpret the output. Explain all the
columns

line-1:{system-summery} 
	top - 11:52:26 up  2:57,  1 user,  load average: 0.29, 0.47, 0.44
explaination:
- 11:52:26 -> Current system time
- up 2:57 -> System uptime (how long the system has been running -> here ~3 hours)
- 1 user -> Number of users logged in
- load average: 0.29, 0.47, 0.44 -> Average CPU load(on cores) over the last 1, 5, and 15 minutes


line-2:{tasks summery}
	Tasks: 290 total,   1 running, 288 sleeping,   1 stopped,   0 zombie
explaintion:
- 290 total -> total no of processes
- 1 running -> processes curently running 
- 288 sleep -> processs curently at rest
- 1 stopped -> processes paused (ctrl+z)
- 0 zombie  -> processes dead but not removed yet
free -h

line-3:{cpu usage}
	%Cpu(s):  1.2 us,  0.8 sy,  0.0 ni, 98.0 id,  0.0 wa,  0.0 hi,  0.0 si,  0.0 st 
explination:
us (1.2%) -> User processes (apps you run)
sy (0.8%) -> System (kernel tasks)
ni (0.0%) -> Nice processes (with adjusted priority)
id (98.0%)-> Idle time (CPU doing nothing → good sign here)
wa (0.0%) -> Waiting for I/O (disk, network)
hi (0.0%) -> Hardware interrupts
si (0.0%) -> Software interrupts
st (0.0%) -> Time stolen by hypervisor 

line-4:{ram usage}
	MiB Mem :  11839.7 total,   6233.3 free,   2800.0 used,   3509.9 buff/cache     
explaintion:
11839.7 total -> Total RAM (≈ 11.8 GB)
6233.3 free -> Currently unused
2800.0 used -> Actively used by processes
3509.9 buff/cache -> Used for buffers + cache (Linux uses free RAM as cache to speed up)

line-5:{swap usage (swap is the dedecated portion 4gb on linux which act as ram if the ram is fully allocated)}
	MiB Swap:   4096.0 total,   4096.0 free,      0.0 used.   9039.7 avail Mem 
explaination:
4096.0 total -> Swap space (≈ 4 GB)
4096.0 free -> Unused swap
0.0 used -> Swap not used (good, means RAM is enough)
9039.7 avail Mem -> Available memory for new processes (includes free + reclaimable cache)

PID : process id 
USER: user associated to that process
PR  : pirority of the process
NI  : nice value
VIRT: virtual mem size {Browsers apps reserve large virtual address spaces for performance, but they don’t actually consume it in RAM}
RES : resedent mem (actual ram)
SHR : shared memory (part of RES that can be shared with other processes)
S   : process state (Running , Sleep , Zombie , Idel kernal thread)
CPU : cpu used by process
MEM : mem used by process
TIME+ COMMAND : {min:sec:milli-sec} running command
